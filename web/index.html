使用说明

本画布用『拖拽节点 + 连线』搭一条优化流程，生成 JSON 交给后端执行。典型两阶段：先找光（网格/线扫描扫到阈值）→ 再优化（精调 / 拟合 / 贝叶斯，带约束）。

① 加节点 / 配置目标

左侧『算法节点』点一下加节点（每个有自己的颜色）。选中节点后设：变量、目标、目标模式（最大化/最小化/逼近目标值/扫描）、算法参数、keep 约束（调本目标时保持另一目标不塌）、stop.target（本阶段达到即停）。

② 连线（执行顺序 / 分支 / 循环）

  1. 鼠标移到节点右侧圆点 ＋ 点一下开始连线（有跟随鼠标的预览），再点目标节点成边，Esc 取消。
  2. 连线指向前面的节点＝循环回边，会自动绕行到下方避免和其它线交叉。
  3. 点连线 → 右侧设条件（成立才走这条边，做分支/循环）或删除连线；也可选中按 Delete、或在线上点右键删。

③ 目标条件 / 表达式

顶部 🎯 目标条件 用表格设全局早停（两目标都达标就整体停），也可切到原始表达式。keep / stop.target / 连线条件都用同一套表达式，支持：

  • 变量名与目标名：x1 x2 x3 y1 y2（就是你 VOCS 里的名字）
  • 比较：> >= < <= == !=；逻辑：and or not；括号 ( )
  • 四则运算 + - * / 和函数 abs( ) min( ) max( )
  • 例：y1>=0.98 and y2>=0.95；逼近：abs(y1 - 0.5) <= 0.02；保持：y1 > 0.8

④ 评估 / 场景 / 通道规范 / 成本 / 起始点

左下选仿真场景（单峰/多峰/偏斜峰，Rosenbrock/Rastrigin/Ackley，以及线性灵敏度台）与方式。

通道规范：每个因变量 y 映射到读取设备(光功率计/偏振分析仪…)+参数，标注读取耗时(秒)，并填测量组；每个自变量 x 映射到执行器。引擎只读取某步真正需要的通道——只优化 y1 的步骤不会去读 y2，省掉它的耗时。

测量组（并行/串行）：同一组的通道并行测量，该组耗时取组内最大；不同组（或留空）串行测量，耗时相加。例：光功率+PDL 同组并行、光功率+中心波长 不同组串行。面板会实时预估『读全部通道一次』的耗时，运行后按每步实际读取的通道累计更准的测量总时长。

自定义起始点：勾选后可为每个自变量填优化的起点（而非定义域中点）；也可在运行后的 2D 轨迹图里点击直接选起点（★）。勾安全限位可为每个自变量单独设安全范围。

相对扫描（无绝对坐标）：网格/线扫描的『扫描窗口(相对起点)』参数——填 0 = 全程绝对扫描；填 >0 = 以起点为中心、按该比例开一个相对窗口来扫（真实台架没有绝对坐标，围绕当前位置局部扫更贴近实际）。

每轴超参数：坐标下降可为每个轴单独设步距、单纯形可为每个轴单独设初始 simplex 边长（留空则用统一的比例）。

④c 与 Agent 对话（左下角）

左下角 🤖 Agent 对话 面板：点标题栏可展开/收起（收起后随时点回来）。连接『实时会话』后，在输入框给 Agent 发指令会写入会话，Agent（如 Hermes）用 get_canvas 读到后执行并把结果/说明推回来显示在这里。

④a 灵敏度采集（📐 顶栏按钮）

先测再解：给原点、步距、点数，平台逐轴扫描——每次只动一个自变量、其余钉在原点，测出每个因变量怎么变。出两样东西：

  • 变化曲线（每对 x→y 一张）：蓝点=实测，虚线=原点处切线，绿底=实测线性范围（从原点沿切线向两侧外扩，偏离超过『容差×y跨度』就出界），下方给 ∂y/∂x、R²、曲率。用来看线性度与线性范围到底有多宽。
  • 灵敏度矩阵 ∂y/∂x：行=y、列=x，一键『填入阻尼灵敏度节点』就能直接拿去做多进多出定值（见下一节）。也可『下载采集点 CSV』。

多原点：点『＋ 加一个原点』可在几个工作点各做一遍，矩阵里会显示均值 ± 标准差；某格相对漂移超过 20% 会标红——说明该处非线性强，一个全局矩阵不够用，应分段/按工作点建模。

拟合阶次：一次=直线（斜率即矩阵）；二次=抛物线，斜率取原点处的导数（曲线弯时比整段直线更接近真实的局部灵敏度）。采集结束会自动回到原点，不会把机构留在最后一个扫描点。流程里也可用灵敏度采集节点做同样的事（单原点）。

④b 阻尼灵敏度求解（多进多出定值/标定）

已知灵敏度 ∂y/∂x 和各 y 的目标值时，加阻尼灵敏度求解节点：勾选要定值的 y 填目标、勾选要动的 x，再填灵敏度矩阵（行=y、列=x）。它用阻尼最小二乘(SVD 正则伪逆)解 Δx=阻尼·S⁺·(目标−当前)，比 pinv 数值更稳，迭代把多个 y 同时逼到目标；x/y 维度按勾选自动匹配。

⑤ 运行 / 轨迹图 / 拟合公式

点 ▶ 运行 出指标（含测量耗时/读取次数）+ 轨迹图，三种视图：

  • 收敛：目标(或变量)随评估次数变化；下方算子色带标出每段评估属于哪个算法。
  • 1D：单个自变量 → 单个目标（看某轴的响应曲线）。
  • 2D：两个自变量，点的颜色=目标值；纯函数场景可点响应面等高线叠加真实地形（后端采样）。

拟合类算法（二次/高斯/参数拟合、公式法）运行后会在节点卡片上回显拟合公式（峰位/参数/R²）。点下载轨迹导出每次评估的全部 x 和 y（CSV）。

场景取左下『仿真场景』。调三个优先级权重与噪声档后点搜索；结果按效用排名，可一键『采用』到画布。

设原点、步距、点数即可。出变化曲线（看线性度/线性范围）与灵敏度矩阵（可一键填进『阻尼灵敏度求解』节点）。多给几个原点还能看灵敏度随工作点漂移多少。
