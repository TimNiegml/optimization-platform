使用说明

本画布用『拖拽节点 + 连线』搭一条优化流程，生成 JSON 交给后端执行。典型两阶段：先找光（网格/线扫描扫到阈值）→ 再优化（精调 / 拟合 / 贝叶斯，带约束）。

① 加节点

左侧『算法节点』点一下就加到画布。节点标题栏可拖动摆位，右上角 ✕ 删除节点。

② 连线（决定执行顺序）

  1. 把鼠标移到节点右侧的圆点（带 ＋），点一下开始连线；
  2. 再点目标节点任意位置，即可连成一条边；连线过程按 Esc 取消。
  3. 点一条连线可在右侧设置条件表达式——留空是普通顺序边；填表达式（如 not (y1>=0.95 and y2>=0.9)）就是分支/循环回边，条件成立才走这条边。
  4. 删除连线：点选连线后按右侧『删除连线』按钮，或直接按键盘 Delete/Backspace，或在连线上点右键。

③ 配置目标

选中节点后可设：变量（调哪些自变量）、目标（优化哪个因变量）、目标模式：

  • 最大化 / 最小化：把目标往大/小推；
  • 逼近目标值：驱动 |y - 目标值|→0（需填目标值），做标定/定值很有用；
  • 扫描：只扫不寻优，产特性曲线。

keep 约束：优化本目标时保持另一目标不塌（如调 y2 时 y1>0.8）。stop.target：本阶段达到即停（如找光 y1>0.2）。顶部 until：全局早停，两目标都达标就整体停。

④ 运行与轨迹

点『▶ 运行』后，右下角出结果指标和目标函数轨迹图。可切换『全部 / 间隔 N 点』来看收敛趋势——间隔取点在评估很多时看大势更清楚。

⑤ 小技巧

  • 看不清就用右上角字号滑块放大画布字体。
  • 关键位置有 i 图标，鼠标移上去有操作提示。
  • 『载入示例』一键放一条两阶段流程，照着改最快。
