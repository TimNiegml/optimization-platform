# 平台缺失元件规格

每个缺口只填写可验证信息：

- **名称/类型**：算法、设备、变换、控制节点或可视化。
- **源代码证据**：函数/类/关键调用。
- **语义**：它完成什么；何时开始/结束。
- **输入/输出**：名称、标量/向量/矩阵、shape、单位、范围。
- **状态与副作用**：设备移动、网络、缓存、随机性。
- **安全/失败**：限位、超时、重试、异常、幂等要求。
- **配置 schema**：画布 inspector 需要暴露的字段及默认值。
- **运行时接入**：registry、generator/evaluator、graph runner 中的职责。
- **UI**：节点卡片、端口、结果展示。
- **验收测试**：正常、边界、失败、序列化/回读。

修改提示词格式：

> 请在 optimization-platform 中新增【名称】。依据【源代码证据】，实现【语义】；输入输出为【契约】。需要修改【后端/registry/UI】，保持安全限制【要求】，并添加【测试清单】。未知部分先列假设，不要臆造设备协议。
