# 课程表

## 新手路线

### 1. 第一次寻峰
- 场景：`single_peak`。
- 作业：仅用坐标下降，让 `x1,x2` 优化 `y1`。
- 验收：graph 有一个正确算法节点；运行后 `y1 > 0.9`；用户能指出 state 是 x、objectives 是 y。

### 2. 找光再精调
- 作业：网格或螺旋扫描 → Nelder-Mead，找光阶段配置 `stop.target`。
- 验收：节点顺序正确；`y1 > 0.98`；用户能解释粗搜和精调分工。

### 3. 保持耦合做均衡
- 作业：在课程 2 后加入 x3→y2 的拟合/公式节点，并设置 `keep: y1>0.8`。
- 验收：`y1 > 0.9` 且 `y2 > 0.9`；keep 存在；无无限循环。

### 4. 会看轨迹
- 作业：运行课程 3，切换收敛/1D/2D 视图，选择坐标并下载或口述关键点。
- 验收：用户正确指出起点、终点、主要增益来自哪个阶段及一次无效采样。

## 进阶路线

### 5. 条件与受限循环
- 作业：搭建一条带条件回边的流程。
- 验收：回边有条件；节点访问有上限；目标达成或限幅退出；用户解释不会死循环的原因。

### 6. 先测灵敏度再求解
- 场景：`linear_sens`。
- 作业：采集 ∂y/∂x，填入阻尼灵敏度节点，把多个 y 驱到目标。
- 验收：矩阵行列匹配；目标误差满足课程设定；用户解释阻尼与正则的用途。

### 7. 观测仪与矩阵
- 作业：在两个算法节点间加入标量观测仪；声明一个练习矩阵通道并用矩阵表或 feature 曲线查看。
- 验收：观测仪位于执行路径；标量结果可见；矩阵行/列 feature 方向解释正确。

### 8. 自动调优与泛化
- 作业：设置质量/速度/稳定权重，搜索候选；演示至少两个策略和两个随机 Case。
- 验收：能读帕累托图；能用 2D 轨迹、收敛曲线、达标率和耗时解释选择，而非只选排名第一。

## 自由挑战

给出“多峰找主瓣并保持 y2”的需求。要求用户：
1. 独立搭图并写目标条件；
2. 比较两条策略；
3. 诊断至少三次运行；
4. 只依据 reliable issue 修改；
5. 用 frozen 审计做最终验收。
