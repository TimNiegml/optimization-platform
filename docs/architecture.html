声明式 IR 是唯一真相；所有界面都只是它的编辑器；执行核只认 IR；算法、硬件、模型、评判都是可插拔件；安全与打分两条底线独立且不可绕过。

公理五条不可动摇

  1. IR 是唯一真相所有界面都只是它的编辑器。一旦让某个 UI 持有独占状态，四个入口立刻分叉。
  2. 算法统一 ask / tell算法永远不知道 f 是仿真、代理模型还是真实电机——这是"换算法 / 换硬件互不影响"的根。
  3. 编排自研且薄通用算法有开源，"迭代优化 + 硬件在环 + 受限循环"的编排没有。这是差异化，也是唯一必须自己扛的复杂度，所以算子集固定，不做图灵完备。
  4. 安全护栏独立、不可关闭限位在 Evaluator 层 clamp；循环强制限幅；全局预算熔断；条件走 asteval 白名单而非 eval。任何算法或编排的 bug 都不能命令越界运动。
  5. 打分确定性，LLM 只读证据若允许 LLM 影响评分，"优化算法"会退化成"优化如何说服裁判"。

红线重构时不能破的

  • 执行路径只有一条：任何入口最终都走 StageEngine，不要为某个前端开旁路。
  • 安全限位、循环限幅、预算熔断不提供关闭开关，也不接受 IR 里的参数把它们调成无穷。
  • 条件表达式只走 asteval 白名单，永不 eval；LLM 产出的 IR 必须过 schema 校验才能执行。
  • 分数只由确定性题库产生；诊断可以给建议区间，但越界会被 schema 夹回。
  • IR 加字段一律可选 + 有默认，存量方案 JSON 必须还能跑。
  • 新依赖先核 license，permissive 才用，并登记 THIRD_PARTY_LICENSES.md。
