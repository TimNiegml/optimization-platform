optplat · device interface

接一台新硬件，你只写一个文件

平台与仪器之间只有三个方法的耦合面：轴的 move / get，测量的 get。 写好一个设备文件，平台自动读出有几个自变量、几个因变量，把算法、安全限位、计时、画布和 Agent 全套上——算法层永远不知道下面是仿真还是真实台架。

改造四步，按顺序做

01

复制模板

examples/device_template.py → your_device.py，放在仓库外也行，接口靠导入路径，不靠位置。

02

写轴（自变量 x）

get() 必须读真实当前位置，不是上次下发的目标值——优化起点从它来，真实台架没有绝对坐标。

from optplat.userdev import Axis, Meter, Source

class StageAxis(Axis):
    def move(self, value):  stage.move_abs(self.name, value)
    def get(self):          return stage.position(self.name)   # 读编码器

AXES = [
    StageAxis("x1", low=-2.0, high=6.0),
    StageAxis("x2", low=-5.0, high=3.0, resolution=0.001),
]
03

写测量（因变量 y）

一次触发出多个通道就用 Source；各自独立读取的仪器照旧用 Meter。两者可以混用。

def _read_pm():
    p1, p2 = pm.read_both()                # 一次触发，返回两个功率
    return {"power1": p1, "power2": p2}

pm_src = Source("pm", _read_pm, cost=1.0, device="双通道光功率计")

METERS = [
    pm_src.meter("y1", "power1", mode="maximize"),
    pm_src.meter("y3", "power2", mode="target", target=0.0),
    Meter("y2", pol.read_pdl, mode="minimize", cost=2.0, device="偏振分析仪"),
]

需要在导入时连仪器，就改用 build() 返回 (axes, meters)，把副作用关在函数里。

04

接线跑起来

python run_device.py your_device.py               # 命令行直接跑，不依赖后端
python run_device.py your_device.py graph.json    # 跑指定的图 IR
OPTPLAT_DEVICE=your_device.py python -m optplat.api   # 画布 / REST / MCP 全用它

第三种下 /vocs 直接返回你的 x/y，起点自动取轴当前位置；/surface 对真实设备返回 400（没有解析响应面，2D 等高线不可用，轨迹图正常）。

规范字段速查

Axis必填语义
name✅变量名，进 VOCS，图 IR 里引用它；必须唯一且不与目标名重名
low / high✅软件量程 = 算法搜索边界
move(value)✅移动到绝对位置，应阻塞到位；否则用 settle_time 覆盖运动时间
get()✅读真实当前位置 → 优化起点
resolution最小步距，供算法参考
Meter默认语义
name / get()必填目标名；读一次测量
modemaximizemaximize / minimize / target
target—mode="target" 时的目标值
cost0.0读一次的秒数，用于耗时模型与画布预估
group—同组并行测（耗时取 max），不同组串行（相加）
device / param—通道映射标注，画布显示"哪台仪器的哪个参数"
Source语义
Source(name, read_fn, cost, group, device)read_fn() 返回 dict，键即通道名；每次调用必须真的触发一次采集
.meter(y, key, mode, target, …)把一个通道暴露成目标 y；cost/group/device 缺省继承 Source
.read() / .invalidate()平台调用，你不要手动调

不变量四件不要做的事

自己缓存读数你看不到采集边界。平台在每轮平均前才失效缓存；自己缓存会让 averages=8 变成同一个数重复 8 次，平均失效、噪声评估全错
自己做多次平均averages 由平台/画布控制，再平均一次就是双重平均，耗时统计也不准
自己 clamp 越界安全限位是独立一层（可 clamp 可抛错），下面再夹一次会掩盖上层 bug
在读数里移动轴 / 在移动里读数平台假设 move 与 read 分离，settle_time 才有意义
